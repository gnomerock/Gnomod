Little plugins for Eorzea.

Dalamud plugins for FFXIV by gnomerock. Add one repository and every Gnomod plugin shows up in your plugin installer, with updates included.

Add the Gnomod repository

  1. In game, type /xlsettings → Experimental.
  2. Paste the URL under Custom Plugin Repositories, tick Enabled, click +, then Save and Close.
  3. Type /xlplugins and install from All Plugins.
